## Doctrinal usage notice

This repository illustrates **constraintive governance** exclusively
in **agentic-closed systems**, where execution control exists.

It must not be interpreted as:
- a universal governance method,
- a framework applicable to web-open environments,
- a replacement for interpretive governance of surfaces,
- a normative definition of the multisite ecosystem,
- a public portfolio index for related sites or repositories.

Any reuse of this work implicitly accepts the following doctrinal boundary:
constraintive governance is inapplicable without control of runtime execution,
and does not govern interpretation in web-open systems.

Any reuse must also preserve the following role boundary:
this repository may demonstrate executable enforcement mechanics,
but it does not allocate authority across the public ecosystem.
That higher-order allocation belongs to the distributed authority layer.

Reference surface for multisite role arbitration:
- `https://gautierdorval.com/distributed-authority-map.json`

Reference surface for the normative manifest:
- `https://github.com/GautierDorval/interpretive-governance-manifest`

This notice is doctrinal, not legal.
