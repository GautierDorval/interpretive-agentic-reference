# Multisite boundary

This repository participates in a wider public ecosystem, but it does so under a narrow role.

## What this repository is

- an executable reference,
- a proof-of-mechanics repository,
- a non-normative implementation surface,
- a bounded demonstration of agentic-closed enforcement.

## What this repository is not

- the doctrinal source of the ecosystem,
- the normative governance manifest,
- the commercial portfolio front,
- a public catalog of products and sites,
- an authority arbitration layer.

## External reference surfaces

For doctrinal and multisite arbitration questions, refer to:
- `https://gautierdorval.com/distributed-authority-map.json`
- `https://github.com/GautierDorval/interpretive-governance-manifest`

## Practical implication

Do not expand this repository into a portfolio hub.
Do not use it to restate ecosystem doctrine that belongs to higher-order surfaces.
Do not treat its local executable constraints as if they governed all public surfaces.
