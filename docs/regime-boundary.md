# Regime boundary

This repository is scoped to **agentic-closed** systems.

In web-open environments, constraintive governance is inapplicable because:

- execution parameters are not controllable,
- orchestration is not controllable,
- validators and refusal logic are not under your authority.

In agentic-closed environments, constraintive governance becomes applicable
and can act as a runtime substrate enabling interpretive constraints to be enforced.
